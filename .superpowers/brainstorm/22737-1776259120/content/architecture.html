架构设计

采用标准 SwiftUI 分层架构，三层清晰分离

优点

  • 原生纯 Swift/SwiftUI，无第三方依赖，编译体积小
  • 符合 Swift 社区最佳实践，易于维护
  • 测试方便，各层可独立测试

不足

  • 需要了解 Swift 开发（但你只需要使用，不需要开发）

层级结构

项目结构
SkillManager/
├── App/                # 入口和主窗口
├── Views/              # SwiftUI 视图层
│   ├── SkillList.swift
│   ├── SkillDetail.swift
│   ├── WorkspaceSection.swift
│   └ ...
├── ViewModels/         # 视图状态逻辑
│   ├── SkillListViewModel.swift
│   └ ...
├── Models/             # 数据模型
│   ├── Skill.swift
│   ├── Workspace.swift
│   └ ...
├── Services/           # 业务服务层
│   ├── SkillScanner.swift      # 扫描技能目录
│   ├── SQLiteReader.swift      # 读取 Duet SQLite
│   ├── SkillMover.swift        # 移动技能
│   ├── FileSystem.swift        # 文件操作封装
│   └ ...
└── Resources/          # 资源文件

数据模型

Skill
- id: UUID
- name: String
- description: String?
- author: String?
- path: URL
- location: LocationType
  - global / workspace
- isEnabled: Bool
- workspaceId: UUID?
Workspace
- id: UUID
- name: String
- path: String?
- rootPath: String
- skills: [Skill]
